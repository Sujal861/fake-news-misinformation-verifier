How to read this

Risk is not proof

The red-flag score describes the message — its urgency, its missing source, its scare tactics. Manipulative wording is a strong hint, but only a fact-check or a cited source can settle whether the claim is true. That is why a message with red flags but no evidence is reported as unverified, never as false.

Offline first, better with keys

The heuristic engine, claim extraction and scam detection run with no network and no accounts. Add a fact-check API key, a web-search key or an LLM key and the same report gains published reviews, live sources and multilingual reasoning — each provider that is missing only downgrades its own contribution.

What to do with the answer

Use the suggested reply to answer the person who forwarded it with a source instead of an argument. Never send money, an OTP or a PIN to anyone who reached you through a forward.

ForwardCheck is an aid, not an authority. It can miss context and it can be wrong — check the linked sources yourself before acting on a claim.
